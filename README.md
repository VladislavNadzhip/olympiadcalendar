# Календарь математических олимпиад

## Описание
Веб-приложение для организации и отслеживания математических олимпиад для школьников. Календарь позволяет просматривать олимпиады по месяцам, добавлять новые мероприятия и управлять информацией о них.

## Особенности

### Главная страница (Год)
- Отображение 12 месяцев в виде карточек
- Интуитивная навигация по календарю
- Современный дизайн с градиентным фоном

### Календарь месяца
- Детальный просмотр выбранного месяца
- Отображение олимпиад непосредственно в днях календаря
- Цветовая индикация событий
- Возможность добавления олимпиад кликом на день

### Карточка олимпиады (боковая панель)
При клике на олимпиаду справа выдвигается панель с подробной информацией:
- Название олимпиады
- Дата и время проведения
- Сложность (легкая/средняя/сложная/очень сложная)
- Целевой класс школьников
- Место проведения
- Ссылка на официальный сайт олимпиады
- Ссылка на архив задач прошлых лет
- Кнопка регистрации на олимпиаду
- Функции редактирования и удаления

### Управление олимпиадами
- Добавление новых олимпиад через удобную форму
- Редактирование существующих записей
- Удаление олимпиад
- Выбор цвета для визуального различия событий
- Все данные сохраняются в localStorage браузера

## Технологии
- HTML5
- CSS3 (с использованием Grid и Flexbox)
- Vanilla JavaScript (без фреймворков)
- LocalStorage для хранения данных

## Установка и использование

1. Склонируйте репозиторий:
```bash
git clone https://github.com/VladislavNadzhip/olympiadcalendar.git
```

2. Откройте файл `index.html` в браузере

Или просто скачайте все три файла (index.html, styles.css, script.js) в одну папку и откройте index.html.

## Как использовать

1. **Просмотр года**: На главной странице выберите интересующий месяц
2. **Просмотр месяца**: Кликните на карточку месяца для детального просмотра
3. **Добавление олимпиады**: 
   - Нажмите кнопку "+ Добавить олимпиаду" или
   - Кликните на конкретный день в календаре
4. **Просмотр деталей**: Кликните на олимпиаду в календаре
5. **Редактирование**: В боковой панели нажмите "Редактировать"
6. **Удаление**: В боковой панели нажмите "Удалить"
